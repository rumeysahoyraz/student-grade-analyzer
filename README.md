# Student Grade Analyzer

A beginner-level C++ project developed to practice arrays, loops, conditional statements, and basic mathematical operations.

## Features
- Store student names and grades using arrays
- Calculate average grade
- Find highest and lowest grades
- Count passed and failed students
- Display students who passed

## Concepts Practiced
- Arrays
- For loops
- Conditional statements
- Basic input/output
- Type casting
- Variables and functions (to be added)

## Future Improvements
- Grade sorting
- Input validation
- File handling
- Menu-based interface
